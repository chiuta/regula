## [0.2.1] - 2026-11-20

### Changed
- fff-kit 1.8.1: when the browser blocks or lacks storage (`localStorage`/`sessionStorage` throw or are missing), the page now starts with temporary in-memory storage instead of stopping; data is not kept after the page is closed.
- fff-kit 1.8.1: the guide that enlarges small controls to 44 px now also measures the width of the page body and of the parent, so a row of buttons can no longer run off the screen (the group is left untouched when enlarging would make it too wide).

## [0.2.0] - 2026-11-17

### Added
- Five playable games as data files in `data/games/`: Nine Men's Morris, Alquerque, Fanorona, Mū tōrere, Hnefatafl (Copenhagen 11 × 11, simplified), each with sources and notes on the choices made.
- A rules engine (`src/engine.mjs`) for two-player games on grid and graph boards: placing, steps, slides, flying, jumps, approach and withdrawal, mills, custodial and king capture, restricted points, win and draw rules; a computer opponent (minimax with alpha–beta pruning).
- Interface: a labelled button for every point (mouse, touch, keyboard, screen reader), a player type for each side, undo and redo, hint, move record, rules written in eight languages from the game data, and your own game as JSON (validate, play, download).
- `schema.json` extended (board, pieces, rules, status, names, notes); `docs/moves.md` (the format) and `docs/tutorial.md` (20 minutes), in English and Romanian, with a tested example game.
- Tests: `node --test` for the engine (move counts worked out by hand), the data and the documentation; browser tests in the hub (eight languages, accessibility, hostile stored state, small screens).
- `src/` and `scripts/build.mjs`: the single `index.html` is now built from sources, and `--check` verifies it.
- ISSUES_GOOD_FIRST and CODE_OF_CONDUCT translated into all eight languages.
- README in English, Romanian, French, Italian, Spanish, Portuguese, German and Hungarian: status and planned scope sections (derived from `ISSUES_GOOD_FIRST.md`).
- Installable (PWA): `manifest.webmanifest`, `sw.js` and icons generated by the shared kit (`fff-kit/pwa`); the page works offline after the first visit over HTTPS.

### Changed
- The workflow runs on Ubuntu 26.04 with Node.js 26 and also runs the tests and the build check.
